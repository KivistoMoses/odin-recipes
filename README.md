#Odin Recipes

This project is a basic HTML recipe website built as part of The odin project curriculum.

## Overview
The goal of this project is to demonstrate basic web development skills using HTML,including setting up standard boilerplate, creating links between pages, displaying images and structuring lists

## Skills Demonstrated
* Writing semantic HTML element markup
* creating text links and relative page navigation
* Adding images with proper 'alt' text
* Structuring ordered and unordered lists
